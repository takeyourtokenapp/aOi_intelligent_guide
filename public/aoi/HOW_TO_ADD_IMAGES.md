# Как добавить изображения aOi

## Быстрая инструкция

Поместите изображения в эту папку (`/public/aoi/`) со следующими именами:

```
/public/aoi/
  ├── beginner-neutral.png    (новичок, спокойное выражение)
  ├── explorer-thinking.png   (исследователь, задумчивое)
  ├── builder-excited.png     (строитель, воодушевлённое)
  └── guardian-neutral.png    (хранитель, спокойное)
```

## Требования к изображениям

### Технические
- **Формат**: PNG с прозрачностью
- **Размер**: минимум 512×512px, рекомендуется 1024×1024px
- **Цветовое пространство**: sRGB
- **Оптимизация**: для web (сжатие без потери качества)

### Визуальные

#### Обязательно:
- Современный аниме стиль
- Возраст 16-18 (образовательный персонаж)
- Большие выразительные глаза
- Мягкая улыбка
- Минималистичная одежда (худи/куртка)
- Пастельные цвета (лаванда, голубой, белый)
- Тонкие tech-детали (бейдж, браслет, интерфейсные элементы)

#### Запрещено:
- Сексуализация
- Гламурная фотография
- Лайфстайл эстетика
- Слишком детский вид

## Уровни aOi

### 🌱 Beginner (beginner-neutral.png)
- Максимальная эмпатия и мягкость
- Цвета: мягкая лаванда, пастельно-розовый
- Минимум tech-деталей
- Выражение: мягкое, приветливое
- Фон: мягкий пастельный градиент

### 🔍 Explorer (explorer-thinking.png)
- Более чёткий взгляд
- Цвета: голубой, лаванда
- Маленький бейдж или браслет
- Выражение: любопытное, умное
- Фон: слабые схемы/диаграммы

### 🔨 Builder (builder-excited.png)
- Более взрослые черты
- Цвета: белый, tech-синий
- Interface glow, несколько элементов
- Выражение: профессиональное, сфокусированное
- Фон: голографические элементы

### 🛡️ Guardian (guardian-neutral.png)
- Максимальная собранность
- Цвета: полный спектр с золотыми акцентами
- Command center интерфейс
- Выражение: защищающее, мудрое
- Фон: продвинутый tech-интерфейс

## Генерация изображений

### Использование AI генераторов

Скопируйте промпты из `/src/config/aoiAssets.ts`:

```typescript
// Базовый промпт для всех
AOI_PROMPTS.master

// Затем добавьте специфичный:
AOI_PROMPTS.beginner  // для beginner-neutral.png
AOI_PROMPTS.explorer  // для explorer-thinking.png
AOI_PROMPTS.builder   // для builder-excited.png
AOI_PROMPTS.guardian  // для guardian-neutral.png
```

### Рекомендуемые генераторы
- Midjourney (лучшее качество аниме)
- DALL-E 3 (хороший контроль)
- Stable Diffusion + anime models

### Workflow
1. Скопировать master prompt + level prompt
2. Сгенерировать несколько вариантов
3. Выбрать лучший (соответствует гайдлайнам)
4. Оптимизировать для web
5. Сохранить с правильным именем
6. Поместить в `/public/aoi/`

## После добавления

Компонент `AoiAvatar` автоматически:
- Попытается загрузить изображение
- Если изображение есть → покажет его
- Если нет → покажет красивый fallback с каджи 葵

## Тестирование

После добавления изображений проверьте:
- Домашняя страница (hero section)
- Foundation страница (header)
- Academy страница (header)
- Панель чата с aOi

---

**Важно**: Все изображения должны отражать суть aOi — эмпатию, интеллект и доверие.
