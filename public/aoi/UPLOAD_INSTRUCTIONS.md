## Как загружать

### Способ 1: Через StackBlitz UI (рекомендуется)

1. В файловом дереве StackBlitz откройте папку `public/aoi/`
2. Перетащите файл мышкой в эту папку
3. Убедитесь, что имя файла **ТОЧНО** совпадает с именами выше
4. Напишите в чат: "Загружен [имя файла]"
5. Я подтвержу загрузку и обновлю проект

### Способ 2: Копировать-вставить

1. Откройте изображение на вашем компьютере
2. Скопируйте файл (Ctrl+C)
3. В StackBlitz: правый клик на папке `aoi/` → Paste
4. Переименуйте файл, если нужно
5. Напишите в чат: "Загружен [имя файла]"

## Важно

**Имена файлов должны быть ТОЧНО такими:**
- Используйте строчные буквы (lowercase)
- Используйте дефисы `-`, не подчёркивания `_`
- Расширение `.png` (не `.jpg`, не `.jpeg`)
- Никаких пробелов в именах

**Неправильно:**
```
Aoi-Fullbody-Welcome.png   ❌ заглавные буквы
aoi_fullbody_welcome.png   ❌ подчёркивания
aoi-fullbody-welcome.jpg   ❌ неправильное расширение
aoi fullbody welcome.png   ❌ пробелы
```

**Правильно:**
```
aoi-fullbody-welcome.png   ✅
portrait-close.png         ✅
hero-welcome.png           ✅
```

## Что происходит дальше

После загрузки каждого файла:

1. Я проверю, что файл загружен корректно
2. Проверю размер и формат изображения
3. Пересоберу проект (`npm run build`)
4. Подтвержу, что изображение готово к использованию
